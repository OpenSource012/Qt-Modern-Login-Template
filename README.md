

# Premium Qt Login UI ✨

A modern, sleek, and fully animated Login/Signup UI template built with **C++** and **Qt 6**. Designed with the beautiful [Catppuccin](https://github.com/catppuccin/catppuccin) color palette, featuring smooth screen transitions and tactile mechanical buttons.

## 🚀 Features

* **Light & Dark Mode:** Seamlessly toggle between themes with a beautiful circular reveal animation.
* **Modern Aesthetic:** Uses the Catppuccin (Latte/Mocha) color palette for a premium, eye-pleasing experience.
* **Tactile UI Elements:** Custom 3D mechanical buttons that provide a satisfying visual click feedback.
* **Smooth Transitions:** Hardware-accelerated sliding animations between Get Started, Login, and Signup screens.
* **Modular Architecture:** Clean, component-based code structure making it incredibly easy to integrate into your own production-grade Qt projects.
